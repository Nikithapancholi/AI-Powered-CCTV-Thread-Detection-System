# CCTV AI Surveillance Dashboard

An AI-powered web app for real-time CCTV video analysis and threat detection.

## Features
- Upload CCTV footage for AI analysis
- Detects CROWD anomalies, VIOLENCE, WEAPONS, SUSPICIOUS behavior
- AI-generated incident summaries (Gemini 2.0 Flash)
- SMS alerts for critical threats
- Analysis history dashboard
- User authentication via Supabase

## Tech Stack
- React 19, TypeScript, Vite
- Tailwind CSS, Framer Motion
- Supabase (Auth + Database)
- Google Gemini 2.0 Flash API
- FFmpeg (video processing)

## Setup
1. Clone the repo
2. Run `npm install`
3. Add your `.env` variables (Supabase URL, Gemini API key)
4. Run `npm run dev`
